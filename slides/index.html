Scenarios

Adding scenarios to our app


A common use for a DES app is to compare scenarios with different inputs.

Our current app shows results for one run at a time. Changing the inputs and running again replaces the previous results.

To compare scenarios, we need to:

  1. Save each run’s inputs and results.
  2. Allow users to view and compare saved scenarios.

Two pages: run scenarios and explore results

As shown, our app now splits the original simulation page into two:

  • Run simulation: set inputs and run the model.
  • View results: view results from a saved scenario or compare several.


Why?

These pages support two different tasks: setting up simulations and making sense of their results. Users can move between them without having to do both in the same place.

This keeps the interface manageable if we add more inputs, results and comparison features.

New dictionary in session state

We first create an empty dictionary in session state, ready to store scenario results.

st.session_state.scenarios = {}


We need to make sure it is only created it if it doesn’t already exist.

This is because Streamlit reruns the script when users interact with the app. Without this check, each rerun would replace the dictionary with an empty one, clearing any saved results.

if "scenarios" not in st.session_state:
    st.session_state.scenarios = {}

New dictionary in session state

We’ll initialise the dictionary in app.py, which runs before whichever page the user opens.


Why not in simulation.py?

Users might open the results page before running a simulation. If we created the dictionary only in simulation.py, it wouldn’t exist yet, causing an error.

Putting this code in app.py ensures the dictionary exists before either page needs it.

"""Entrypoint for app. Defines navigation."""

import streamlit as st

pg = st.navigation(
    [
        st.Page("home.py", title="Home"),
        st.Page("simulation.py", title="Run simulation"),
    ]
)

pg.run()

# Session state set-up
# Doing it here as otherwise if click straight on view results get error
if "scenarios" not in st.session_state:
    st.session_state.scenarios = {}

Run and save the results

In simulation.py, we’ll keep the code that sets the inputs and runs the simulation.

We’ll remove the analysis code for now and move it to the results page later. We can also remove import plotly.express as px as this page no longer uses it.

After the code to run the simulation, we’ll add new code to:

  1. Name the scenario

  2. Save its settings and results in st.session_state.scenarios.

"""Simple single-page app."""

import streamlit as st
from model import Param, Trial

with st.container(border=True):
    st.subheader("Patients")

    st.slider(
        label="Mean patient inter-arrival time (minutes)",
        min_value=3.0,
        max_value=7.0,
        value=5.0,
        step=0.25,
        key="mean_patient_inter",
    )

    st.subheader("Nurses")

    st.number_input(
        label="Mean nurse consultation length (minutes)",
        min_value=3.0,
        max_value=9.0,
        value=6.0,
        key="mean_nurse_consult_time",
    )

    st.number_input(
        label="Standard deviation of nurse consultation length (minutes)",
        min_value=0.0,
        value=1.0,
        key="sd_nurse_consult_time",
    )

    st.pills(label="Number of nurses", options=range(1, 5), default=1, key="num_nurses")

    st.number_input(
        label="Cost per nurse per hour (£)",
        min_value=0.0,
        value=30.0,
        step=1.0,
        key="nurse_cost_per_hour",
        help="Nurses are costed for the full simulation duration, including time when they are not seeing patients",
    )

    st.space(size="xxsmall")
    st.subheader("Simulation")

    st.slider(
        label="Simulation duration (minutes)",
        min_value=50,
        max_value=200,
        value=120,
        key="sim_duration",
    )

    st.slider(
        label="Number of replications",
        min_value=10,
        max_value=50,
        value=30,
        key="num_replications",
    )

if st.button("Run simulation", type="primary"):
    params = Param(
        mean_patient_inter=st.session_state.mean_patient_inter,
        mean_nurse_consult_time=st.session_state.mean_nurse_consult_time,
        sd_nurse_consult_time=st.session_state.sd_nurse_consult_time,
        num_nurses=st.session_state.num_nurses,
        sim_duration=st.session_state.sim_duration,
        num_replications=st.session_state.num_replications,
        nurse_cost_per_hour=st.session_state.nurse_cost_per_hour,
    )
    trial = Trial(param=params)
    trial.run_trial()
    trial.calculate_trial_results()

    # Save results to session state to allow comparison between scenarios
    scenario_name = f"Scenario {len(st.session_state.scenarios) + 1}"
    st.session_state.scenarios[scenario_name] = {
        "settings": {
            "Scenario": scenario_name,
            "Inter-arrival": st.session_state.mean_patient_inter,
            "Consultation mean": st.session_state.mean_nurse_consult_time,
            "Consultation SD": st.session_state.sd_nurse_consult_time,
            "Nurses": st.session_state.num_nurses,
            "Cost per hour": st.session_state.nurse_cost_per_hour,
            "Duration": st.session_state.sim_duration,
            "Replications": st.session_state.num_replications,
        },
        "mean": trial.trial_mean_q_time_nurse,
        "sd": trial.trial_sd_q_time_nurse,
        "p90": trial.trial_perc_90_q_time_nurse,
        "se": trial.se_q_time_nurse,
        "ci_lower": trial.ci_lower_q_time_nurse,
        "ci_upper": trial.ci_upper_q_time_nurse,
        "cost": trial.total_nurse_cost,
        "df": trial.replication_df,
    }
